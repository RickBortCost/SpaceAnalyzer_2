> **How the screenshots were made.** The images are captured automatically from Space Fieldbus Analyzer {{version}} (built from the code of the RickBortCost/SpaceFieldbusAnalyzer_Free repository and run on Linux) with the `tools/guide/capture.py` tool. The data are simulated: a demonstration OPC UA server with eight plant signals, three sample recordings (one acquired by the application, one synthetic at 1 kHz for the FFT, two for the comparison), a test InfluxDB server and a temporary PostgreSQL. They do not come from the Windows EXE or from a real PLC. The launcher splash, native ADS (TwinCAT), symbolic S7, SSH Debug with a real host and connections to production InfluxDB/PostgreSQL servers were not tested: they are described from the project documentation.
