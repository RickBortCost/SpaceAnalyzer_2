# 4. Scansione e scelta dei segnali

![scan](Pannello «Address Space · scansione» (colonna sinistra della pagina LIVE).)

| N. | Controllo |
|---|---|
| 1 | **Nodo di partenza**: radice della navigazione (`i=85` = Objects). |
| 2 | **Limite nodi** per scansione (predefinito 50.000). |
| 3 | **Esplora rami**: apre l'albero un ramo alla volta, utile su server molto grandi. |
| 4 | **Scansiona tutto**: percorre l'intero address space (nell'esempio centinaia di nodi, 0 errori) con barra di avanzamento e pulsante Interrompi. |
| 5 | **Lista scansione / Albero**: due modi di consultare i risultati. |
| 6 | **Cerca** per nome, percorso o NodeId. |
| 7 | **Solo variabili**: nasconde cartelle e oggetti. |
| 8 | **Seleziona risultati**: aggiunge al trend tutte le variabili filtrate. |

Si può anche spuntare una singola riga («Grafico») o inserire un NodeId a mano in «Aggiungi NodeId / gestione». I segnali selezionati compaiono nella colonna «Segnali live» con valore corrente, qualità e tipo. Solo le variabili numeriche entrano nel trend; le altre restano consultabili e registrabili. Fino a 64 segnali complessivi. Durante Record la selezione resta fissa fino a Stop.
