> **Come sono state ottenute le schermate.** Le immagini sono acquisite automaticamente dal servizio Space Fieldbus Analyzer {{version}} (compilato dal codice del repository RickBortCost/SpaceFieldbusAnalyzer_Free ed eseguito su Linux) con lo strumento `tools/guide/capture.py`. I dati sono simulati: un server OPC UA dimostrativo con otto segnali di impianto, tre registrazioni di esempio (una acquisita dall'applicazione, una sintetica a 1 kHz per la FFT, due per il confronto), un server InfluxDB di prova e un PostgreSQL temporaneo. Non provengono dall'EXE Windows né da un PLC reale. Lo splash del launcher, ADS nativo (TwinCAT), S7 simbolico, Debug SSH con un host reale e le connessioni a server InfluxDB/PostgreSQL di produzione non sono stati provati: sono descritti dalla documentazione del progetto.
